# Pingviper
Just a dumb script that automates ping sweeps.

Usage

```
Usage: pingviper.sh [-h] [-f <file>] [-s <Subnet>] [-m <Mask>]
```

Options

```
-h                 Show this help message and exit
-f                 Take a txt file with the subnets and masks (ex. 10.0.0.0/24)
-s                 Set subnet
-m                 Set mask
```
